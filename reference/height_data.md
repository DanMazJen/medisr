# Howell !Kung Demography Data

Demographic data from Kalahari !Kung San people collected by Nancy
Howell.

## Usage

``` r
height_data
```

## Format

### `height_data`

A data frame containing demographic measurements of !Kung San
individuals:

- height:

  Height in cm

- weight:

  Weight in kg

- age:

  Age in years

- male:

  Gender indicator

- age.at.death:

  Age at death in years, if deceased

- alive:

  Indicator of whether the individual is still alive
